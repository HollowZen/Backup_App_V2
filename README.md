# Полнофункциональное приложение для резервного копирования

Мощное настольное приложение для создания и управления резервными копиями файлов и папок с современным интерфейсом WPF и расширенными функциями безопасности.

## 🚀 Основные возможности

### 📁 Типы резервного копирования
- **Полная копия (Full)**: Копирование всех файлов
- **Инкрементальная (Incremental)**: Копирование файлов, измененных с момента последнего бэкапа
- **Дифференциальная (Differential)**: Копирование файлов, измененных с момента последнего полного бэкапа

### 🔒 Безопасность данных
- **Шифрование AES-256**: Защита бэкапов с использованием PBKDF2 для генерации ключей
- **Windows DPAPI**: Безопасное хранение паролей в системе
- **Защита от несанкционированного доступа**

### 📅 Автоматическое планирование
- **Гибкое расписание**: Ежедневное, еженедельное, ежемесячное выполнение
- **Двойная система таймеров**: Основной (30 сек) + точный (5 сек) для максимальной точности
- **Фоновое выполнение**: Независимое от UI выполнение задач

### ☁️ Облачное хранение
- **Yandex.Диск интеграция**: Автоматическая загрузка бэкапов в облако
- **REST API**: Полноценная работа с облачным хранилищем
- **Отказоустойчивость**: Возобновление прерванных загрузок

### 🧹 Управление хранением
- **Политики очистки**: Удаление старых версий по количеству или возрасту
- **Автоматическая оптимизация**: Освобождение дискового пространства
- **Настраиваемые правила**

### 📊 Мониторинг и уведомления
- **Журнал операций**: Подробная история всех бэкапов с фильтрацией
- **Системные уведомления**: Tray-иконка с баллунами о статусе операций
- **Прогресс-бар**: Отображение текущего состояния выполнения

### 🎨 Пользовательский интерфейс
- **Современный дизайн**: WPF с MVVM архитектурой
- **Интуитивное управление**: Вкладки для всех настроек
- **Асинхронные операции**: Отзывчивый интерфейс во время работы

### 🔧 Технологии
- **Язык**: C# 12.0 (.NET 8.0)
- **UI**: Windows Presentation Foundation (WPF)
- **База данных**: SQLite + Entity Framework Core 8.0
- **Паттерн**: Model-View-ViewModel (MVVM)
- **DI**: Microsoft.Extensions.DependencyInjection
- **Криптография**: AES + PBKDF2
- **Облако**: Yandex.Disk REST API

## 📋 Системные требования

- **ОС**: Windows 10/11 (64-bit)
- **RAM**: Минимум 512 MB
- **Диск**: Минимум 100 MB свободного места
- **Framework**: .NET 8.0 Runtime или SDK

## ⚡ Быстрый запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/HollowZen/Backup_App_V2.git
   cd Backup_App_V2
   ```

2. **Создайте миграцию базы данных**:
   ```bash
   cd BackupApp.Data
   dotnet ef migrations add InitialCreate
   dotnet ef database update
   ```

3. **Запустите приложение**:
   ```bash
   cd ../BackupApp.WPF
   dotnet run
   ```

## 🎮 Руководство пользователя

### Создание новой задачи резервного копирования

1. **Нажмите "Создать"** в главном окне
2. **Вкладка "Основные"**:
   - Укажите имя задачи
   - Выберите папку источника (кнопка "...")
   - Выберите папку назначения (кнопка "...")
   - Установите галочку "Задача включена"

3. **Вкладка "Расписание"** (опционально):
   - Выберите тип: Ежедневно/Еженедельно/Ежемесячно
   - Установите время в формате HH:mm
   - Для еженедельного: выберите дни недели
   - Для ежемесячного: выберите число месяца

4. **Вкладка "Параметры копирования"**:
   - Выберите тип бэкапа: Полный/Инкрементальный/Дифференциальный
   - Установите уровень сжатия ZIP (0-9)

5. **Вкладка "Шифрование"** (опционально):
   - Установите галочку "Использовать шифрование AES"
   - Введите пароль шифрования (минимум 8 символов)

6. **Вкладка "Хранение"** (опционально):
   - Выберите политику: Сохранять все/Максимум версий/Максимальный возраст
   - Укажите соответствующие параметры

7. **Вкладка "Облако"** (опционально):
   - Установите галочку "Загружать в облако"
   - Введите токен доступа к Yandex.Диск
   - Укажите папку в облаке

8. **Нажмите "Сохранить"**

### Управление задачами

- **Запуск задачи**: Выберите задачу и нажмите "Запустить"
- **Изменение**: Выберите задачу и нажмите "Изменить"
- **Удаление**: Выберите задачу и нажмите "Удалить"

### Просмотр журнала

- **Меню**: Вид → Журнал операций
- **Фильтры**: Успешные/Ошибки/Предупреждения, по задаче
- **Экспорт**: Возможность сохранить логи в файл

## 🔧 Расширенная настройка

### Подключение к Yandex.Диск

1. Получите токен доступа на [oauth.yandex.ru](https://oauth.yandex.ru/)
2. В настройках задачи укажите токен
3. Проверьте подключение кнопкой "Тест"

### Политики хранения

- **KeepAll**: Сохранять все версии бэкапов
- **MaxVersions**: Хранить только N последних версий
- **MaxAge**: Удалять бэкапы старше N дней

### Шифрование

- Алгоритм: AES-256-CBC с PBKDF2
- Ключ выводится из пароля PBKDF2 с солью (10,000 итераций)
- Пароль хранится в зашифрованном виде через Windows DPAPI

## 🔌 API Интеграции

### Yandex.Dиск REST API

Приложение использует следующие endpoints:
- `GET /v1/disk/resources/upload`: Получение ссылки на загрузку
- `PUT /upload-target`: Загрузка файла
- `GET /v1/disk/resources/download`: Получение ссылки на скачивание
- `DELETE /v1/disk/resources`: Удаление файла

### Windows DPAPI

Для безопасного хранения паролей используется:
```csharp
ProtectedData.Protect(userData, entropy, DataProtectionScope.CurrentUser)
ProtectedData.Unprotect(encryptedData, entropy, DataProtectionScope.CurrentUser)
```
